# Edge-Cloud-Simulation
Python + SimPy 기반 Edge/Cloud Computing simulation

## 연구 목적

Edge와 Cloud 환경에서 task offloading 성능을 비교한다.

## 주요 변수
# 독립변수

- RTT
- Bandwidth
- Packet Loss
- Edge CPU Utilization
- Cloud CPU Utilization
- Workload
- Data Size

#종속변수
- application latency
- throughput

## 클래스

- Network
- EdgeServer
- CloudServer
- Task
